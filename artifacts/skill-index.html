分類

分類順序、以及同分類內的卡片順序都可以拖曳調整，調整後會自動保存。

更新技能清單

這一頁讀不到你的 skill 目錄（發佈後的頁面沒有檔案系統權限）。 在讀得到的環境跑 python3 scan-skills.py，把輸出的 JSON 整段貼進來即可。 套用後會存進這個 Artifact 的資料檔，之後每次打開都會直接讀到最新的清單。

新增 skill

這一頁沒有權限把 skill 裝進你的帳號。它會產生一份合規的 SKILL.md， 你下載或複製後到 claude.ai 上傳，設定頁就會出現。填的中文名與分類會存成草稿， 之後掃描到這個 skill 時自動沿用，不必重打。

接下來：下載或複製後，到 claude.ai → Settings → Capabilities → Skills → 上傳， 設定頁就會看到它。下次掃描時儀表板會自動把草稿換成實際安裝的版本。
